Срок выполнения - 1 декабря

**Задание:**

**Часть 1 - 1 балл**

1. Изучите файл 3\_5\_(1).
2. Создайте массив входных значений;
3. Выберите 2 библиотечные функции numpy и 2 полинома;
4. Постройте 4 различных графика. Оформление каждого графика должно отличаться от других. Выведите на нескольких графиках легенду, измените подписи к осям, используйте разные типы линий (и разную ширину), маркеры. Выведите подписи к экстремумам функции (1 график). Отобразите сетку на нескольких графиках.
5. Сохраните графики в файл.
6. В качестве ответа необходимо прикрепить файлы изображений и ноутбук.

![Упражнение](https://edu.susu.ru/pluginfile.php/8414390/mod_assign/intro/example.png)

**Часть 2 - 3 балла**

1. Изучите файл 3\_5\_2.
2. Выберите любой набор данных (в формате csv/txt), включающий календарные данные, открытый для скачивания в сети Интернет.
3. Постройте 3D графики трех типов под разными углами.
4. Прикрепите файл в формате .ipynb в качестве ответа на задание.
