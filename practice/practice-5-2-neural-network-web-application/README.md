Реализуйте веб приложение, которое обладает следующими функциями:

    Принимает от пользователя изображение цифры и возвращает ему распознанную цифры. В качестве модели для распознавания используйте нейронную сеть, полученную на практических занятиях по дисциплине "Глубокое обучение". 
    Пользователь оценивает правильность работы модели. Например, нажимает кнопку "Верно" или " Не верно". Изображение с меткой сохраняется в соответствующей папке. Изображения, собранные приложением, могут использоваться для дообучения модели.
